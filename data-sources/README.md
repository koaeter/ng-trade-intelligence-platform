# Data Sources

This directory documents external and internal information sources.

## Planned source groups

### Nigeria

- Laws and legislation
- Regulations and subsidiary instruments
- Government gazettes
- Agency requirements
- Standards and procedures
- Official trade/export publications

### International

- WTO
- ITC
- UN Comtrade
- World Bank
- Regional and bilateral trade instruments
- Other authoritative datasets

Each source should eventually have documented:

- Authority
- URL/API endpoint
- Data type
- Update frequency
- Licensing/access conditions
- Ingestion method
- Provenance requirements
- Reliability/validation approach
