# Domain Model

The domain model will describe the real-world concepts represented by the platform.

Initial concepts include:

- Product
- HS Code
- Country
- Exporter
- Importer
- Market
- Law
- Regulation
- Guideline
- Standard
- Circular
- Treaty
- Agreement
- MOU
- Agency
- Requirement
- Certificate
- Tariff
- Non-Tariff Measure
- Trade Flow
- Effective Period
- Source
