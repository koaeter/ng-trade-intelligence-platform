# Pass 100 — Initial Nigerian regulatory source corpus

The registry now has a first controlled corpus of real Nigerian authority sources identified from current official public websites:

- NEPC export documents/procedures and e-registration
- SON standards and product-certification information
- NAFDAC export e-license and processed/semi-processed food export-health-certificate guidelines
- NAQS export requirements and plant quarantine guidance
- Nigeria Customs Service export procedure

These are deliberately registered as sources rather than published requirements. Their current content must still pass acquisition, extraction, candidate review and publication before it can influence compliance evaluation.
