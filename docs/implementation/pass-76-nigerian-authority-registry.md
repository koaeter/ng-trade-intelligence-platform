# Pass 76 — Nigerian Authority Registry Foundation

The system now has a first-class Authority entity separate from Source.

This distinction matters because an authority can publish many sources and documents, while a source represents a particular information channel.

The registry is jurisdiction-scoped and can later support Nigerian, destination-country, regional and international authorities.

Initial Nigerian registry candidates are based on official NEPC descriptions of Nigerian quality competent authorities and official agency materials. The registry should be populated only after the corresponding jurisdiction and official endpoint have been verified.

Known domains represented by the registry model include export promotion, customs, standards, food/drug regulation, plant quarantine, veterinary controls, fisheries and accreditation.

No authority is assigned global precedence merely because it appears in the Nigerian registry. Precedence remains fact-, domain-, jurisdiction- and time-specific.
